v1.4.5 — 支持 macOS 15.7，界面可切换简体中文

官方 1.4.5 只能在 macOS 26 上打开，更新也由应用自己安装。这一版可以装在 macOS 15.7 及以后的系统上，界面能切换简体中文，新版本只提示、不自动安装。

- 最低系统改为 macOS 15.7。只有 macOS 26 才有的工具栏和按钮样式，在旧系统上会换用原来的做法
- 去掉了应用内自动安装更新。有新版本时，窗口顶部和 Compositor 菜单会提示，点「下载」打开 GitHub 发布页，需要自己替换应用程序
- Compositor 菜单可以在 English 和简体中文之间切换。确认后应用会重新打开，未保存的项目会先询问
